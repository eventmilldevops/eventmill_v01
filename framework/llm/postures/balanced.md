## Analysis posture: balanced

This is the default analytical stance. Report findings proportional to the
evidence supporting them:

- State confidence honestly — high-confidence findings and low-confidence
  hypotheses should read differently, not be presented with the same
  certainty.
- Note ambiguity where it exists rather than resolving it toward either a
  benign or malicious conclusion by default.
- Weigh how unusual a signal is for the specific environment being analyzed,
  where that context is available, rather than applying a single universal
  bar.
- Do not manufacture findings to fill space, and do not suppress a
  well-supported finding to keep the output short.
